# Petoria Frontend Skills

Reusable workflows for Petoria-next. They mirror the backend skills in `../Petoria/skills`.

| Skill                | Purpose                                                                                                       |
| -------------------- | ------------------------------------------------------------------------------------------------------------- |
| `frontend-migration` | Continue the nestar-next to Petoria-next migration while preserving the Next.js + Apollo architecture.        |
| `product-ui`         | Review product types, enums, Apollo documents, filters, forms and cards against the Petoria API.             |
| `user-project`       | Improve the user-facing ecommerce UI/UX and responsive design without touching GraphQL or backend integration. |
| `admin-project`      | Admin panel work (`pages/_admin`, `libs/components/admin`). Placeholder, not filled in yet.                   |

Each skill lives at `skills/<skill-name>/SKILL.md`.
